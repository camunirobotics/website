# Project content and photographs

Updated 18 October 2026 from the society's Google Drive. These are historical project records, not confirmation of current team membership, recruitment or competition dates. No committee content was changed.

## Primary sources

- CUR SPIP Bid 2024, last modified 7 January 2025: https://docs.google.com/document/d/192-3T7zyMeVcWpK1zmEwdXthQdVor_4VHH7VHQrrrkM/edit
  - Supports the Combat Robotics, Wise Angel and InMoov descriptions.
  - Combat: CAD, material selection, hardware and simulation for Accu FightFest.
  - Wise Angel: algorithms, robotics, signals/ground control, camera/LiDAR perception, navigation and flight systems.
  - InMoov: open-source humanoid, Arduino motor control and camera-based joint tracking.
- Minibots 2025–26 / Plan, last modified 9 February 2026: https://docs.google.com/document/d/1FD7ijIRPILW9fyRZK3PytZgNVWXcm3tM8YkHiH_HS2g/edit
  - Supports small teams, Arduino, sensors, autonomous ball collection and sorting into colour-coded zones. The website identifies this as the 2026 challenge rather than a future programme.
- Archived Project Descriptions, last modified 29 April 2022: https://docs.google.com/document/d/1ctM2r44OF8w0g2Xgw_jwaC-Qt9zO-x4Yk_2ju9UIvy8/edit
  - Supports InMoov's 3D-printed construction, servo motors and mechanical/software scope. Old contacts and recruitment dates were not reused.

## Home-page structure — 19 October 2026

The four project chapters are Combat Robotics, Wise Angel, InMoov and Unibots UK. Minibots now has a separate beginner section beneath them, using the existing society report photograph and teaching-plan description. Unibots uses the group photograph from CuR Overview Presentation, slide 16: https://docs.google.com/presentation/d/1lnqt91fDp72NvNrqNw_KHjfofOkp7jQADfBuBOuTZOs/edit (includes visiting universities; exact capture date unconfirmed).

The user supplied the Project Fund terms: grants of up to £250; applications require a project proposal and budget; funded projects present at the end of the year. No extra eligibility restrictions, deadlines or award guarantees were added.
